# Changelog - B2TRAC

Todas las actualizaciones notables de B2TRAC serán documentadas en este archivo.

El formato se basa en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/).

## [1.0.0] - 2026-08-10

### ✨ Características Añadidas
- Portal dual (Vendedor / Cliente)
- Gestión completa de pedidos
- Administración de clientes
- Carga y almacenamiento de documentos (fotos, facturas, guías)
- Estadísticas y dashboards
- Descargas en formato Excel
- Integración con Supabase
- Soporte multi-tenant (estructura preparada)
- Configuración de branding por cliente
- Variables de entorno para personalización

### 🎯 Portal Vendedor
- Vista de pedidos totales y en curso
- Crear nuevos pedidos
- Ver detalles de pedidos
- Monto total gestionado
- Listado de clientes
- Subida de documentación

### 📊 Portal Cliente
- Resumen de pedidos
- Historial de compras
- Total comprado y deuda actual
- Descargar reportes en Excel
- Estado de pedidos
- Ver detalles de transacciones

### 🔧 Stack Técnico
- Next.js 14.0.0
- React 18.2.0
- Supabase 2.38.0
- Axios 1.4.0
- XLSX 0.18.5
- PapaParse 5.4.1

### 📝 Documentación
- README.md con guía completa
- Instrucciones de instalación
- Configuración de base de datos
- Guía de deployment en Vercel
- Estructura de variables de entorno

### 🏗️ Estructura Mejorada
- Organización de carpetas estándar Next.js
- Separación clara de componentes por portal
- Utilitarios centralizados
- Configuración de tenant
- Archivo de licencia propietaria
